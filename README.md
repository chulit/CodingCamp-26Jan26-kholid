# ☕ Lumina Coffee Website

A modern, responsive, and visually appealing website for **Lumina Coffee**, an artisanal coffee shop brand. This project demonstrates a polished UI/UX design using **Tailwind CSS**, featuring glassmorphism effects, bento-grid layouts, and interactive elements.

## ✨ Features

-   **Modern UI/UX Design**:
    -   **Glassmorphism**: Stylish frosted glass effects on the navbar and cards.
    -   **Bento Grid Layout**: Organized and aesthetic display for achievements and facilities.
    -   **Typography**: Elegant combination of *Plus Jakarta Sans* for readability and *Great Vibes* for branding.
    -   **Animations**: Smooth transitions, floating elements, and hover effects.
-   **Interactive Elements**:
    -   **Dynamic Greeting**: Personalizes the user experience by storing the visitor's name in `localStorage`.
    -   **Hero Slider**: Auto-playing background image slider on the landing page.
    -   **Contact Form**: Functional form with validation and a real-time "Message Preview" card.
-   **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices with a custom mobile navigation menu.
-   **Pages**:
    -   **Home (`index.html`)**: Landing page with facilities overview and contact form.
    -   **Our Profile (`profile.html`)**: Company history, vision, and mission.
    -   **Achievement (`achievement.html`)**: Showcase of awards and recognitions.

## 🛠️ Tech Stack

-   **HTML5**: Semantic markup.
-   **CSS3**: Custom styles + **Tailwind CSS** (via CDN) for rapid styling.
-   **JavaScript**: Vanilla JS for logic (form validation, slider, local storage).
-   **Fonts**: Google Fonts (*Plus Jakarta Sans* & *Great Vibes*).
-   **Icons**: Custom SVGs.

## 📂 Folder Structure

```
/
├── css/

├── index.html          # Homepage
├── profile.html        # About Us page

```

## 🚀 How to Run

1.  **Clone the repository** (or download the ZIP file).
2.  Open the project folder.
3.  Double-click `index.html` to open it in your default web browser.
    *   *Note: An internet connection is required to load Tailwind CSS and Google Fonts.*
